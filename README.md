# Приложение для дизайн-брифа

Приложение на Next.js 14 помогает собрать расширенную форму "ТЗ NEW с дизайнером", получить краткое резюме через OpenAI (до 1000 символов), сохранить ответы на сервере и сгенерировать референсы через Gemini 2.5 Flash Image. Также доступны выгрузки DOCX/PDF с полным содержимым формы.

## Установка и запуск

1. **Установка зависимостей**
   ```bash
   npm install
   ```
2. **Переменные окружения**
   Создайте файл `.env.local` и укажите ключи OpenAI и Gemini API:
   ```env
   OPENAI_API_KEY=sk-...
   GEMINI_API_KEY=...
   GEMINI_IMAGE_MODEL=gemini-2.5-flash-image-preview # (опционально, значение по умолчанию)
   ```
3. **Запуск в режиме разработки**
   ```bash
   npm run dev
   ```
   Приложение будет доступно по адресу http://localhost:3000.

## Доступные команды

- `npm run dev` – запуск приложения в режиме разработки
- `npm run build` – сборка проекта для продакшена
- `npm start` – запуск собранного проекта

## Функциональность формы

- Выбор типа жилья (новостройка/вторичное) с переключением наборов полей.
- Указание отделки, общей площади и списка помещений с площадями и отметкой помещения для референсов.
- Загрузка файла планировки (jpg/png/pdf) с сохранением в `uploads/` и превью (для изображений).
- Сбор данных о стиле, цветовой гамме, материалах, жителях и особых требованиях.
- Формирование краткого ТЗ (GPT-4o mini) строго до 1000 символов и сохранение результатов в `data/submissions.json`.
- Генерация 4 вариантов референсов через Gemini 2.5 Flash Image, выбор и скачивание нужного варианта.
- Экспорт DOCX и PDF, включающих все введённые поля и метаданные о планировке.

## Примечания

- `.npmrc` закрепляет основной реестр npm.
- Рабочие директории `uploads/` и `data/` игнорируются git и создаются автоматически.
- Не коммитьте реальные API-ключи; файл `.env.local` уже добавлен в `.gitignore`.
